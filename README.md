# cyclemean — 最小平均代价有向回路

`cyclemean.minimum(n, edges)` 用 **Karp 最小环均值算法** 在回流依赖中找出
平均净代价最低的真实回路，全程精确有理数运算，返回可核对的原边见证。

## 接口

```python
from cyclemean import minimum

minimum(2, [(0, 1, 2), (1, 0, 4), (1, 1, 5)])
# -> (3, 1, [0, 1])   即平均代价 3/1，见证为原边 0、1 构成的回路 0->1->0
```

* 输入：节点 `0..n-1`（`1 <= n <= 500`），`edges` 为至多 20000 条
  `(u, v, cost)`（整数，可负，允许自环与平行边）。输入只读，绝不被修改。
* 输出：无有向环时返回 `None`；否则返回 `(p, q, edge_ids)`：
  * `p/q` 为全图所有非空有向回路的最小平均代价，`p`、`q` 互质且 `q > 0`；
  * `edge_ids` 按行走顺序给出**原边下标**，首尾闭合、除首尾外节点不重复，
    其平均代价恰为 `p/q`（多个最优回路时任选其一）。

## 方法

1. **Karp DP**：`D[k][v]` = 恰好 k 条边、终于 v 的最短路径代价
   （`D[0][v] = 0`，等价于超级源点）。逐行松弛全部边，记录父边。
2. **精确最优值**：`λ* = min_v max_{0<=k<=n-1} (D[n][v]-D[k][v])/(n-k)`，
   所有比较均为整数交叉相乘，无浮点近似；结果约分为互质 `p/q (q>0)`。
3. **原边见证**：从取到最优的 `v*` 沿父指针回溯 n 步得到 n 边行走路径，
   首个重复节点截出简单回路——Karp 界在 `v*` 处取等保证该回路均值恰为
   `λ*`。只返回原图中的边下标，不合成新边。

复杂度：时间 `O(n·(n+m))`，空间 `O(n·n + m)`（不枚举回路）。

```bash
python3 verify_cyclemean.py   # 全部核验（退出码 0 = 通过）

```

验证使用与核心完全独立的判定器：

* **小图穷举**：枚举所有简单回路取最小均值（n=2 全图集 455 个 +
  2000 个随机小图 + 60 个随机中图）；
* **见证核对**：边下标合法、行走顺序首尾闭合、节点不重复、
  `总代价·q == p·长度`；
* **最优性**：Bellman-Ford 在移位整数权重 `q·c - p` 上检测负环，
  确认不存在均值严格更小的回路；`None` 答案由 Kahn 拓扑排序独立确认；
* **实测规模**：稠密有环图与大规模无环区域均为 n=500、m=20000，
  另含 19997 边无环区域中埋藏单个回路的用例；
  覆盖不连通分量、负环、平行边、自环。
